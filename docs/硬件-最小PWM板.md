# 最小 PWM 板 · 硬件设计

> 建立：2026-11-17
> 目标：**能做、能跑、能验证**，不追求功能全
> 供白佳正画板用（立创 EDA）

---

## 一、需求（明确边界）

```
输入：7.4V（2S LiPo）
输出：5V  （给舵机 + 激光模块 + 备用）
     3.3V（给 C8T6）

功能：
  · C8T6 最小系统
  · 4 路 PWM 输出（排针，接 4 个舵机）
  · 1 路 UART1（PA9/PA10，接树莓派）
  · SWD 调试口
  · 电源开关 + 保险
  · 电源指示灯（3.3V / 5V）
```

**★ 明确不做：**
```
✗ CAN / USB / SPI / I2C
✗ 多路 UART
✗ 电池电量检测
✗ 复杂保护电路
→ 这些都留给"下一版"
```

---

## 二、电源架构

```
7.4V 输入
  │
  ├─[5A 自恢复保险]
  ├─[PMOS 防反接]（AO3401 + 10k/100k 分压）
  ├─[电源开关]
  │
  ├──→ [Buck 7.4V→5V / 5A]  ──→ 5V 轨
  │      MP2315 或 MP1584        ├── 4 路舵机（排针）
  │                              ├── 激光模块（排针）
  │                              └── 备用 5V 输出
  │
  └──→ [LDO 5V→3.3V / 800mA] ──→ 3.3V 轨
         AMS1117-3.3 或 SPX3819   ├── C8T6
                                  ├── 晶振
                                  └── 传感器（以后）
```

### 器件选型

| 位置 | 器件 | 参数 | 备注 |
|---|---|---|---|
| **Buck** | **MP2315** | 7.4V→5V，5A | ★ 推荐（5A 余量大）|
| Buck 备选 | MP1584 | 7.4V→5V，3A | 便宜，3A 够 2 个舵机 |
| **LDO** | **AMS1117-3.3** | 5V→3.3V，1A | 常见，便宜 |
| LDO 备选 | SPX3819 | 5V→3.3V，500mA | 低噪声（ADC 用）|
| **防反接** | **AO3401**（PMOS）| -30V/-4A | 压降仅 0.05V |
| **保险** | 自恢复保险 | 5A | 或插片保险座 |
| **输入电容** | 电解 100µF/25V | ×2 | Buck 输入 |
| **输入陶瓷** | 10µF/25V | ×2 | 高频去耦 |
| **输出电容（5V）** | 电解 220µF/10V | ×1 | 舵机大电流缓冲 |
| **输出陶瓷（5V）** | 22µF/10V | ×2 | |
| **输出电容（3.3V）** | 10µF | ×2 | |
| **分压电阻**（FB）| 按 Buck 手册算 | — | 设 5.0V |

**★★★ 关键：5V 输出电容要够大（220µF）**
```
舵机启动瞬间拉 2A
→ 没有大电容缓冲 → 5V 塌陷 → C8T6 复位
```

## 三、C8T6 最小系统

### 必须的元件

| 项 | 规格 | 数量 | 说明 |
|---|---|---|---|
| **C8T6** | LQFP48 | 1 | |
| **晶振** | 8MHz | 1 | 外部 HSE |
| **晶振负载电容** | 20pF | 2 | ★ 按晶振手册调 |
| **复位电容** | 100nF | 1 | NRST 到 GND |
| **复位按钮** | 轻触开关 | 1 | 并联在复位电容上 |
| **BOOT0 下拉** | 10kΩ | 1 | 到 GND（从 Flash 启动）|
| **BOOT1 下拉** | 10kΩ | 1 | 到 GND |
| **去耦电容** | 100nF | **每个 VDD 引脚 1 个** | ★ 必须，缺一不可 |
| **总去耦** | 10µF | 2 | 电源入口 |
| **VDDA 滤波** | 100nF + 10µF | 1 组 | 模拟电源 |

### C8T6 的电源引脚（LQFP48）

```
VDD_1  (pin 24)
VDD_2  (pin 36)
VDD_3  (pin 48)
VDDA   (pin 9)   ← 单独 100nF + 10µF
VSS_1  (pin 23)
VSS_2  (pin 35)
VSS_3  (pin 47)
VSSA   (pin 8)
VBAT   (pin 1)   ← 接 3.3V（不用电池备份）
```

**★★★ 每个 VDD 旁边 100nF，位置要紧贴引脚（< 3mm）**

## 四、引脚分配（本板）

| 功能 | 引脚 | 板上体现 |
|---|---|---|
| **USART1_TX** | **PA9** | 排针 |
| **USART1_RX** | **PA10** | 排针 |
| **PWM1** | **PA0** (TIM2_CH1) | 排针（舵机 1）|
| **PWM2** | **PA1** (TIM2_CH2) | 排针（舵机 2）|
| **PWM3** | **PA2** (TIM2_CH3) | 排针（舵机 3）|
| **PWM4** | **PA3** (TIM2_CH4) | 排针（舵机 4）|
| **SWDIO** | **PA13** | 排针（4 pin: 3.3V/SWDIO/SWCLK/GND）|
| **SWCLK** | **PA14** | 同上 |
| **NRST** | — | 复位按钮 + 排针 |
| **BOOT0** | — | 跳线帽（可选，方便改启动模式）|

**★★ 4 路 PWM 全用 TIM2（PA0~PA3）—— 一个定时器，4 通道，最简单。**

**★ 好处：**
```
· 只需配一个定时器
· 4 路同频（50Hz），只是占空比不同
· PA0~PA3 连续，布线方便
```

## 五、接口布局（板子草图）

```
┌─────────────────────────────────────────┐
│  [7.4V IN] [开关] [保险] [LED-5V]       │
│                                          │
│  ┌─── Buck 区 ───┐   ┌── LDO ──┐        │
│  │   MP2315       │   │ AMS1117 │        │
│  └───────┬────────┘   └────┬────┘        │
│          │5V               │3.3V         │
│  ┌───────┴────────────────┴──────┐      │
│  │        C8T6 核心区             │      │
│  │  [晶振] [复位] [去耦×N]        │      │
│  └───┬───────┬────────┬──────────┘      │
│      │       │        │                  │
│  [PWM×4 排针] [UART 排针] [SWD 排针]    │
│   +5V/GND      TX/RX       4pin          │
│                                          │
│  [激光模块 5V 排针] [备用 5V 排针]      │
└─────────────────────────────────────────┘
```

### 排针定义

| 排针 | 引脚顺序 |
|---|---|
| **PWM 舵机区**（2×4 或 2×5）| `5V / GND / PWM1 / PWM2 / PWM3 / PWM4` |
| **UART**（1×4）| `3.3V / TX / RX / GND` |
| **SWD**（1×4）| `3.3V / SWDIO / SWCLK / GND` |
| **激光模块**（1×2）| `5V / GND` |
| **备用 5V**（1×2）| `5V / GND` |

**★★ 舵机排针要用**带卡扣的**（XH2.54 或 PH2.0），普通排针会松。**

## 六、板子规格

```
尺寸：50 × 40 mm（建议）
层数：★ 2 层够（这是最小板，不用 4 层）
板厚：1.6mm
铜厚：1oz
颜色：任意
```

**★ 为什么 2 层够：**
```
· 信号最高 115200 UART（慢）
· 没有差分对（没有 CAN/USB）
· 电流最大 5A（走线加宽即可）
```

### 走线宽度

| 网络 | 宽度 | 原因 |
|---|---|---|
| **7.4V 输入** | **≥ 2.0mm** | 5A |
| **5V 主路** | **≥ 1.5mm** | 3A |
| **3.3V** | **≥ 0.5mm** | 500mA |
| **PWM 信号** | 0.25mm | 小电流 |
| **GND** | 铺铜 | — |

---

## 七、画板要点（立创 EDA）

```
① 先放 Buck（MP2315）的典型电路
   → 数据手册里的参考电路，直接抄，不要自己改
   → ★ 输入回路面积要小（C_in → SW → GND 的环路）

② 电感靠近 Buck 的 SW 引脚（< 5mm）

③ 5V 输出电容（220µF）靠近舵机排针

④ 晶振靠近 C8T6（< 10mm），下方禁止走线

⑤ 每个 VDD 的 100nF 紧贴引脚

⑥ 舵机排针的 5V/GND 走粗线，直接连 Buck 输出电容

⑦ 铺铜：顶层和底层都铺 GND，用多个过孔连接

⑧ SWD 排针要有 3.3V（给 ST-Link 参考）
```

## 九、验收方法（打样回来后）

```
① 空板测：7.4V 和 GND 不短路（万用表蜂鸣档）
② 只焊电源部分 → 上电 → 测：
   □ 5V 轨 = 4.9~5.1V
   □ 3.3V 轨 = 3.2~3.4V
   □ 无发热
③ 焊 C8T6 + 晶振 + 去耦 → ST-Link 能连上
④ 烧录 LED 闪烁固件 → 验证最小系统
⑤ 烧录 PWM 固件 → 示波器/逻辑分析仪看 50Hz
⑥ 接舵机 → 转
```

**★★ 第 ② 步最重要 —— 电源不对，后面全白费。**

## 十、★ 三个最容易犯的错

| # | 错误 | 后果 |
|---|---|---|
| **1** | **忘焊去耦电容** | C8T6 跑飞、ST-Link 连不上 |
| **2** | **7.4V 走线太细** | 发热、压降、烧板 |
| **3** | **5V 输出电容太小** | 舵机一动 MCU 复位 |
