# C8T6 拓展板（底板）设计

> 建立：2026-11-17
> **形态：Blue Pill（C8T6 最小系统模块）插上去的底板**
> 供白佳正画板用（立创 EDA）

---

## 一、和"最小系统板"的区别（重要）

```
❌ 最小系统板：自己画 C8T6 + 晶振 + 复位 + 去耦
   → 要处理 LQFP48 的 48 个引脚、晶振布线、去耦布局
   → 首次画板容易翻车

✅ 拓展板（本设计）：插一个现成的 Blue Pill
   → 只需 2 排 1×20 母座
   → 电源 + 接口
   → ★ 大幅降低难度，且 Blue Pill 坏了直接换
```

---

## 二、Blue Pill 模块规格（★ 画板必须按这个来）

```
尺寸：     53 × 22.5 mm
引脚排：   2 × 20 pin
针距：     2.54 mm
两排间距： 15.24 mm（0.6 英寸，★ 关键！）
```

## 三、电源架构（简化版）

```
7.4V 输入
  │
  ├─[5A 自恢复保险]
  ├─[PMOS 防反接 AO3401]
  ├─[拨动开关]
  │
  └──→ [Buck 7.4V→5V / 5A]
         │
         ├──→ Blue Pill 的 5V 脚（右排第 3 脚）
         │     └── Blue Pill 板载 AMS1117 降到 3.3V
         │
         ├──→ 4 路舵机排针的 5V
         ├──→ 激光模块 5V
         └──→ 备用 5V 排针
```

**★★ 不需要单独的 3.3V LDO！**
```
理由：
· Blue Pill 板载 AMS1117-3.3（800mA）
· C8T6 只吃 50mA
· 3.3V 只给 C8T6 自己用
→ 省一个 LDO，省一片区域

★ 但如果以后要接 3.3V 传感器（IMU、OLED），把 Blue Pill 的 3.3V 引脚引出来即可
```

### 器件选型

| 位置 | 器件 | 参数 | 备注 |
|---|---|---|---|
| **Buck** | **MP2315** | 7.4V→5V，5A | ★ 推荐（5A 余量大）|
| Buck 备选 | MP1584 | 7.4V→5V，3A | 便宜 |
| 电感 | 4.7µH / 3A | 1 个 | 按 Buck 手册 |
| **肖特基** | **SS34** | 1 个 | ★ 5V→Blue Pill 防倒灌 |
| **防反接** | **AO3401**（PMOS）| -30V/-4A | 压降 0.05V |
| **保险** | 自恢复 5A | 1 个 | |
| **开关** | 拨动 2 档 | 1 个 | |
| **输入电容** | 100µF/25V 电解 + 10µF 陶瓷 | 各 1 | |
| **输出电容（5V）** | **470µF/10V 电解** + 22µF + 100nF 陶瓷 | 各 1 | ★ 舵机缓冲 |
| **TVS（7.4V）** | **SMBJ12A** | 1 个 | ★ 输入浪涌 |
| **TVS（5V）** | **SMBJ6.5A** | 1 个 | ★ 舵机反冲 |
| **指示灯** | 5V LED（红）+ 限流 1k | 1 组 | |

**★★★ 5V 输出 470µF 是必须的**
```
舵机启动瞬间拉 2A
→ 没大电容缓冲 → 5V 塌陷 → Blue Pill 复位 → 舵机乱动
```

## 四、排针接口定义

### ① 舵机区（4 路）

```
建议用 XH2.54 端子（带卡扣）而不是普通排针

每个舵机 3 pin：5V / GND / PWM

布局建议（2×4 或 1×12）：
  [5V] [PWM1] [GND] [5V] [PWM2] [GND] ...
  或
  [5V] [5V] [5V] [5V]
  [PWM1] [PWM2] [PWM3] [PWM4]
  [GND] [GND] [GND] [GND]
```

**★ 推荐第二种（3×4 排针）—— 一目了然，不容易插反。**

### ② UART1 区（1×4，接树莓派）

```
[3.3V] [TX] [RX] [GND]
        ↑PA9 ↑PA10
```

### ②b UART3 区（1×4，接上位机 / PC）★ 新增

```
[3.3V] [TX] [RX] [GND]
        ↑PB10 ↑PB11
```

**★★ 为什么用 UART3 而不是 UART2：**
```
UART2 = PA2 / PA3
→ ★ 和 PWM3(PA2) / PWM4(PA3) 冲突！

UART3 = PB10 / PB11
→ ✅ 不冲突，4 路 PWM 全保留
```

**★ Blue Pill 的 PB10 / PB11 在左排第 15 / 16 脚，已引出。**

### ③ SWD 区（1×4）

```
[3.3V] [SWDIO] [SWCLK] [GND]
        ↑ PA13   ↑ PA14
```

**★★ 注意：Blue Pill 的 SWD 口在板子尾部（4 pin），可以直接插 ST-Link，不需要额外排针**

### ④ 激光模块（1×2）

```
[5V] [GND]
```

### ⑤ 备用 5V（1×2）

```
[5V] [GND]
```

### ⑥ 3.3V 引出（1×2，可选）

```
[3.3V] [GND]
```

## 六、画板要点（立创 EDA）

```
① 先放 Blue Pill 的母座（用商城的封装，别自己画）
   → 搜索 "STM32F103C8T6 最小系统板" 的封装模块

② 再放 Buck 的典型电路（MP2315 数据手册参考电路，直接抄）
   → ★ 输入回路面积要小（C_in → SW → GND）

③ 电感靠近 Buck 的 SW 引脚（< 5mm）

④ 5V 输出电容（470µF）靠近舵机排针

⑤ 走线宽度：
   7.4V 输入 ≥ 2.0mm
   5V 主干   ≥ 1.5mm
   PWM 信号  0.25mm

⑥ 铺铜：顶层和底层都铺 GND，多打过孔

⑦ 母座附近留出 Blue Pill 的高度空间（不要放高的元件）
```

## 八、验收方法

```
① 空板测：7.4V 和 GND 不短路
② 只焊电源部分 → 上电 → 测：
   □ 5V 轨 = 4.9~5.1V
   □ 无发热（摸 Buck 芯片）
③ 插 Blue Pill → 上电 → Blue Pill 的 LED 亮
④ ST-Link 能连上（Blue Pill 自带 SWD 口）
⑤ 烧录 PWM 测试固件 → 示波器看 PA0~PA3 的 50Hz
⑥ 接舵机 → 转
```

**★★ 第 ③ 步是关键 —— Blue Pill 能正常工作，说明 5V 供对了。**

## 九、★ 四个最容易犯的错

| # | 错误 | 后果 |
|---|---|---|
| **1** | **母座间距不是 15.24mm** | Blue Pill 插不进去 |
| **2** | **7.4V 走线太细** | 发热、压降、烧板 |
| **3** | **5V 输出电容太小（<100µF）** | 舵机一动 Blue Pill 复位 |
| **4** | **母座焊反（1 脚位置错）** | 插上去烧模块 |

**★★★ 第 1 和第 4 条是"一次性错误"—— 打样回来才发现就全废了。**

**→ 对策：**
```
① 母座间距用游标卡尺量实物 Blue Pill 确认
② 板上丝印标"1"脚位置 + USB 端方向
③ 打样前让第二个人 check 一遍封装
```
