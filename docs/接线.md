# 接线

## 一、树莓派 ↔ STM32（UART）

```
树莓派 GPIO14 (TXD, 物理引脚 8)  ──→  STM32 PA10 (USART1_RX)
树莓派 GPIO15 (RXD, 物理引脚 10) ←──  STM32 PA9  (USART1_TX)
树莓派 GND   (物理引脚 6)         ────  STM32 GND
```

**★★★ TX 接 RX，RX 接 TX（交叉）**

**★ 树莓派端设备：`/dev/ttyS0`（mini UART，之前实测可用）**

---

## 二、STM32 → 舵机

```
STM32 PA0 (TIM2_CH1)  ──→  MG996R 信号线（橙/黄）
```

---

## 三、电源（★ 最关键）

```
外部 5V/3A 电源
  ├── +5V  ──→  MG996R VCC（红）
  └── GND  ──→  MG996R GND（棕）
             ──→  STM32 GND        ★ 共地
             ──→  树莓派 GND        ★ 共地
```

**★★★ 三根 GND 必须连在一起 —— 否则信号参考电平不对，舵机乱抖**

**★★ 绝对不能从 STM32 的 5V 或树莓派的 5V 给舵机供电**
```
MG996R 堵转电流 ~2.5A
STM32/树莓派的 5V 输出 ≤ 500mA
→ 会电压塌陷 → 主控重启
```

---

## 四、ST-Link（烧录）

```
ST-Link          STM32
SWDIO    ──→     PA13
SWCLK    ──→     PA14
GND      ────    GND
3.3V     ──→     3.3V（可选，如果板子已供电就不用）
```

**★ 烧录前确认 CubeMX 里 `SYS → Debug = Serial Wire`（已配）**

---

## 五、接线检查清单

```
□ 树莓派 TX(14) → STM32 RX(PA10)      ← 交叉
□ 树莓派 RX(15) ← STM32 TX(PA9)       ← 交叉
□ 三根 GND 连通（用万用表测）
□ 舵机 VCC 接外部 5V（不接主板 5V）
□ ST-Link 的 SWDIO/SWCLK 接 PA13/PA14
□ 上电前先用万用表测 5V 和 GND 是否短路
```
