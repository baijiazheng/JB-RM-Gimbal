# 串口协议（18 字节二进制帧）

> 波特率：115200 · 8N1 · 无流控
> 字节序：小端（树莓派 ARM 和 STM32 都是小端）

---

## 帧格式

```
偏移  长度  内容          类型      说明
0     2     0xAA 0x55     —         帧头
2     4     yaw           float32   水平角（度），例 12.34
6     4     pitch         float32   垂直角（度），例 -5.67
10    4     dist          float32   距离（米），例 0.35
14    1     fire          uint8     0=不开火 1=开火
15    1     status        uint8     0=无目标 1=跟踪 2=对准
16    1     checksum      uint8     buf[2..15] 求和 & 0xFF
17    1     0x0D          —         帧尾
─────────────────────────────────────────
共 18 字节
```

---

## 树莓派端（发送）

```python
import serial, struct

ser = serial.Serial('/dev/ttyS0', 115200, timeout=1)

def send_pose(yaw, pitch, dist_m, fire=0, status=1):
    payload = struct.pack('<fffBB', yaw, pitch, dist_m, fire, status)  # 14 字节
    checksum = sum(payload) & 0xFF
    ser.write(b'\xAA\x55' + payload + bytes([checksum, 0x0D]))          # 18 字节
```

**★ 验证：`struct.calcsize('<fffBB')` == 14**

## STM32 端（接收）

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart) {
    if (huart->Instance != USART1) return;
    rx_buf[rx_idx++] = rx_byte;

    if (rx_idx >= 2 && rx_buf[rx_idx-2]==0xAA && rx_buf[rx_idx-1]==0x55) {
        rx_idx = 2;                                  // ★ 帧对齐
    } else if (rx_idx >= 18) {
        if (rx_buf[17] == 0x0D) {
            uint8_t sum = 0;
            for (int i = 2; i < 16; i++) sum += rx_buf[i];
            if (sum == rx_buf[16]) {
                float yaw;
                memcpy(&yaw, &rx_buf[2], 4);         // ★ 不要强制类型转换
                g_yaw = yaw;
            }
        }
        rx_idx = 0;
    }
    HAL_UART_Receive_IT(huart, &rx_byte, 1);         // ★ 必须重开
}
```

---

## 三个关键点

| # | 要点 | 为什么 |
|---|---|---|
| **①** | 看到 `0xAA 0x55` 就重置 `rx_idx=2` | 帧对齐（从中间开始读也能恢复）|
| **②** | 用 `memcpy` 不用 `(float*)&buf` | ARM 非对齐访问会 HardFault |
| **③** | 每次回调末尾 `HAL_UART_Receive_IT` | HAL 只收一个字节就停 |

---

## 为什么是 18 字节而不是 ASCII

| | 二进制 18B | ASCII ~30B |
|---|---|---|
| **带宽** | 560 B/s @30Hz | 900 B/s @30Hz |
| **解析** | `memcpy` 直接得 float | `sscanf` 不支持 %f（MCU）|
| **对齐** | 帧头 + 定长 | 换行符 |
| **可读性** | ❌ 要看字节 | ✅ 串口助手直接看 |

**★ 选二进制：MCU 端解析简单、带宽小。调试时用 Python 打印十六进制即可。**
