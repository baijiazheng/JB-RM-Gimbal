## 六、⚠️ 一个必须处理的问题：5V 双电源冲突

```
Blue Pill 的 5V 脚有两个来源：
  ① 板载 USB 口（插 USB 时）
  ② 拓展板 J3 的 5V（DC-DC）

★★★ 如果两个同时接 → 互相倒灌 → 可能烧

解决方案（选一个）：

【方案 A】加跳线帽（推荐）
  J3 的 5V ──[JP1 跳线]── Blue Pill 的 5V
  · 用 DC-DC 时：JP1 短接，不插 USB
  · 用 USB 烧录时：JP1 断开，只插 USB

【方案 B】加肖特基二极管
  J3 的 5V ──|>|── Blue Pill 的 5V（SS14，压降 0.3V）
  · 自动隔离，但 Blue Pill 实际只得到 4.7V
  · ★ Blue Pill 的 LDO 输入 4.7V 还能出 3.3V（压差够）

【方案 C】不加保护，靠操作规范
  · 板上标注"不要同时插 USB 和 DC-DC"
  · ★ 风险：容易忘
```

**★★ 我推荐方案 A（跳线帽）—— 简单、可靠、无压降。**

## 七、电源树（最终版）

```
[XT30 电池输入]
   │
   ├─→ [PTC 3A/6A] → [PMOS 防反接] → [SW1 开关]
   │                      D接电池+/S接负载/G接GND(10k)
   │                      + R1 100k (S-G)
   │
   ├─→ LED(红) + R(470Ω) → GND        ← 电源指示
   │
   ├─→ C 100µF 电解 + 10µF 陶瓷 + 100nF 陶瓷 → GND
   │
   ├─→ +7.4V 输出 (J2) → 外置 DC-DC 模块
   │
   └─→ +5V 输入 (J3) ← DC-DC 输出 5V/5A
          │
          ├─→ [JP1 跳线] → Blue Pill 的 5V（右排第 3 脚）
          ├─→ J4 舵机排针 5V（★ 加 220µF 电解）
          ├─→ J7 激光 5V
          └─→ J8 备用 5V
```

**★★★ 5V 轨上必须加 220µF 电解（舵机缓冲）**

## 八、布线顺序（建议）

```
① 先放 Blue Pill 母座（2×20，间距 15.24mm）
② 再放电源区（XT30 → PTC → PMOS → SW1 → J2/J3）
③ 放 J4~J11 排针（按布局图位置）
④ 走电源粗线（7.4V ≥2mm，5V ≥1.5mm）
⑤ 走信号线（PWM/UART，0.25mm）
⑥ 铺 GND 铜（顶层+底层，多打过孔）
⑦ DRC 检查
⑧ 生成 Gerber
```
